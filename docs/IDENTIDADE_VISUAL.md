# Identidade visual da Fasolo & Simon

Fonte: pacote `00_Fasolo_e_Simon.rar` fornecido pelo usuário durante a versão 0.3. O pacote contém logos em PNG/JPG/PDF e arquivos editáveis AI. Somente o logo horizontal e o símbolo PNG utilizados pelo aplicativo foram incluídos no repositório.

- Azul: `#32464D`, conforme especificação visível na paleta (RGB 50, 70, 77).
- Dourado: Pantone 871 C Metallics. Para telas foi usado `#86764E`, amostrado da imagem de paleta fornecida. Esta cor RGB é uma representação digital e não reproduz o acabamento metálico.
- Logo: arquivo original, sem redesenho, recoloração, distorção ou mudança de lettering. Usar sobre fundo claro, preservando a proporção.
- Tipografia das telas: Arial / Helvetica / sans-serif. O pacote não informa uma fonte por nome nem inclui arquivos TTF, OTF ou WOFF. Essa é uma escolha provisória para a interface, não uma afirmação sobre a tipografia institucional.
- Avisos de protótipo e distinção de estados permanecem visíveis.
